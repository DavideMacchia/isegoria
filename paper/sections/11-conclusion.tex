\section{Conclusion}\label{sec:conclusion}

The central idea of Isegoria is to use opinion as a filter and evidence as the verdict, so that
the decision rests on what an item \emph{does} rather than on what the network \emph{thinks}. That
idea survives the analysis. Each level, however, has a property that the design documents did not
anticipate:
\begin{itemize}
  \item bridging scores are relative to their batch, and at the default penalties they retain most
    of the camp-size effect that bridging is meant to remove;
  \item latent-class DIF can mistake error in the ability proxy for a latent class;
  \item the evaluator's skill score is not proper, and the weight cap never binds;
  \item the anti-collusion discount depends on a detector that has almost no data within an epoch.
\end{itemize}
Each finding now has an adopted correction (\cref{sec:revisions}). Some are supported by a
proof: the side-balanced score is gauge-invariant and camp-balanced (\cref{prop:side}), and
randomized exploration keeps the evaluator score proper (\cref{prop:ipw}). The others rest on the
experiments reported here. None is implemented yet, and none is validated beyond simulation.
The next steps are:
\begin{itemize}
  \item implementing the corrections as the repository's roadmap tasks T49--T57, each starting
    from a test that fails today;
  \item the evaluation plan of \cref{sec:plan}, which turns provisional thresholds into
    characterized ones;
  \item independent review of both the statistics and the cryptography.
\end{itemize}
The paper is versioned with the repository and will be revised as those results arrive.
